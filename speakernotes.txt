SLIDE 4 — HOW IT WORKS (RAG PIPELINE)
────────────────────────────────────────────────────────

Now let me explain HOW it works — because as engineers, the "how" matters.

The technology behind UniAdvisor AI is called a RAG pipeline — Retrieval-Augmented Generation. Here is the five-step process.

Step one — a student types their question into the chat interface.

Step two — the system performs a vector search. This means it mathematically finds the most relevant chunks of information from the university's document library.

Step three — it retrieves those relevant chunks from the knowledge base — which is built from your actual PDFs, handbooks, and course catalogs.

Step four — it passes those retrieved chunks as context to the Large Language Model, which generates a clear, accurate, human-readable answer.

Step five — the student receives a precise answer in under three seconds.

The critical thing to understand is this: the AI never makes things up. Every answer is grounded in the university's own verified documents. This is what makes RAG superior to a standard chatbot.

On the frontend and analytics side: React with TypeScript for a clean, modern interface, Tailwind CSS for responsive design, Recharts for the admin analytics dashboard, complex SQL queries for reporting, Streamlit for the internal admin view, and a full Git and CI/CD pipeline for professional deployment.
